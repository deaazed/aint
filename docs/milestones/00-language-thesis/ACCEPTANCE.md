# Milestone 00 — Language thesis — acceptance

## Scope

Write down what AINT is, what it explicitly is not, and the design
principles later milestones are accountable to, before any compiler code
exists.

## Acceptance criteria

- [x] `docs/LANGUAGE_DESIGN.md` states the thesis in one sentence.
- [x] It lists explicit non-goals (what AINT is not).
- [x] It sketches the type system far enough to know what `Distribution<T>`
      and `Inference<T>` need to support.
- [x] It states the ten implementation design principles.
- [x] It defines what "done" looks like for the project as a whole
      (the milestone 25-27 benchmark), so later milestones have a target
      that isn't just "feels finished."

## Outcome

Satisfied by `docs/LANGUAGE_DESIGN.md`. This document is a living
reference, not a one-time artifact — if a later milestone forces a real
change to the thesis (see milestone 27), update it there and note the
change here.
